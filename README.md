# CYD-ESP32-2432S028RV3介绍
2.8英寸屏CYD-ESP32-2432S028RV3的Arduino库   
这款开发板是V3，带两个USB接口  
基于 LovyanGFX 驱动 ST7796 显示屏和 XPT2046 触摸屏  

# 使用方法
和正常的Arduino库使用方法一样，复制到文档/Arduino/libraries目录
